# PrivacyGuard — Milestone / Phase 개발 로드맵 v0.1

2026-11-25 | 설계 단계, 모든 작업 미착수. 이름·스택·수치 목표는 제안이며 확정된 사용자 요구는 [spec-privacyguard.md](spec-privacyguard.md)의 Decisions Log 참조.

각 Phase는 실제 기능, 자동 테스트, 필요한 경우 Windows VM/실기기 검증, 문서와 남은 한계를 포함한다. 체크박스는 검증 증거가 있어야 완료 처리한다. 도구 설치나 코드 작성만으로 완료하지 않는다. 일정은 추측하지 않으며 선행 조건과 종료 기준으로 진행한다.

## M0 — 프로젝트 기반 및 안전한 실험 환경
- [ ] P0.1 이름/저장소 및 초기 OS 버전 결정, 라이선스/의존성 목록과 호환성 검토. 공개 전 라이선스 확정.
- [ ] P0.2 C#/.NET LTS, GUI/CLI 공통 정책 계약과 모듈 구조, 단위 테스트 구성.
- [ ] P0.3 SECURITY.md, CONTRIBUTING.md, AGENTS.md, PR 템플릿, 이슈 템플릿, ADR 및 기능별 capability 문서.
- [ ] P0.4 GitHub Actions: 빌드·단위 테스트, CodeQL, Dependabot, 비밀 탐지(지원 범위 확인), 의존성 검토, 고정된 Actions 버전/SHA, 최소 권한. 문서만 수정 시 무관한 빌드 제외하되 필수 체크가 영구 대기하지 않게 설계.
- [ ] P0.5 Windows VM 스냅샷, 자체 테스트 앱/로컬 시험 서버, 가짜 민감 데이터와 host canary, 깨끗한 기준선 구축.
- 종료: 재현 가능한 개발 빌드, 실행 가능한 테스트 환경, 승인된 라이선스 및 문서, 운영 OS에 변경 없음.

## M1 — 읽기 전용 관찰 (최초 개발자 프리뷰)
- [ ] P1.1 프로그램 인벤토리·프로세스 생명주기와 PID 재사용 처리.
- [ ] P1.2 ETW/공식 이벤트 공급자 검토, 파일·레지스트리 등 관찰 가능한 범위 식별. 공급자별 권한·누락 카운터.
- [ ] P1.3 네트워크 연결 메타데이터/가능한 바이트 집계, IPv4/IPv6, TCP/UDP, 공유 서비스는 미귀속 표시.
- [ ] P1.4 로컬 이벤트 저장·마스킹·보존·디스크 상한, UI/CLI에서 조회.
- [ ] P1.5 대시보드·앱 상세·타임라인, 사실/추론/미확인 구분. 초기 한국어/영어 및 접근성.
- [ ] P1.6 무통신 기본값, 유실·권한 부족·재시작·높은 이벤트 부하 테스트 및 베이스라인 비교.
- 종료: 자체 테스트 앱 활동의 관찰 범위가 실제 측정과 일치; 유실·미지원이 보임; 비밀 원본을 저장하지 않음. 보호 제품이 아니라 관찰용 실험판임을 명시.

## M2 — 검증 가능한 통신 보호
- [ ] P2.1 Windows Firewall 연동, 계획/적용/조회/복구 계약, 제품 소유 규칙 ID 및 권한 브로커.
- [ ] P2.2 앱별 통신 제한·허용 정책, 기존 조직/사용자 정책 존중. 기본 경로와 업데이트 후 앱 재확인.
- [ ] P2.3 목적지 정책 및 로컬 DNS 연동 연구, 공유 IP/DoH/VPN/IPv6 한계 검증. 검증된 기능만 공개.
- [ ] P2.4 추적 목록의 출처·서명·예외·오탐 신고, 목록 다운로드는 옵트인.
- [ ] P2.5 브로커 비인가 호출·정책 충돌·중단 중 복구·재부팅·재설치·제거 테스트.
- 종료: 자체 클라이언트와 로컬 시험 서버에서 허용/거부의 실제 성공/실패를 독립 관측. 다른 앱 및 기존 방화벽 규칙 불변. 제품 규칙 완전 복구.

## M3 — 정책 엔진 및 일반 사용자 경험
- [ ] P3.1 앱별 프로필·균형 기본·호환/엄격/사용자 정의/임시 정책 스키마. OS에 없는 기능은 unavailable.
- [ ] P3.2 적용 가능 항목의 실시간 승인, 기억·기간 제한·취소, 알림 집계, 타임아웃 및 승인 없는 보호 완화 방지.
- [ ] P3.3 초기 마법사, 시스템 트레이, 권한·오류·복구 UI, CLI와 동일한 정책 경로.
- [ ] P3.4 위험도 설명, 로그 관리·내보내기 전 검토·마스킹, 성능 통계와 자원 설정.
- [ ] P3.5 상태 재조회, 장애 진단, 긴급 중지, 중단/충돌/다중 사용자/업데이트/시간 변화 시험.
- 종료: 지원 기능의 정책 일치, 승인 및 취소 검증, 실패 상태 명시, UI/CLI 결과 동일. 임시 격리 등 미지원 모드는 기능을 제공한다고 홍보하지 않음.

## M4 — Windows 첫 정식 출시 (1.0 후보)
- [ ] P4.1 OS 지원 버전별 실제 테스트, Windows VM 및 실제 PC에서 설치·실행·보호·제거 검증.
- [ ] P4.2 보안 리뷰 및 취약점 처리, 권한 경계·로그·업데이트 공급망 독립 검증.

- [ ] P4.4 서명된 실행 파일, 빌드 출처 증명·SBOM·SHA-256, 독립 재빌드 비교(서명 전 산출물 기준도 문서화), 업데이트/롤백 정책.

## 운영 방식

PR 하나당 검증 가능한 범위. 이슈에는 요구사항 ID, 테스트 ID, 영향, 제외 범위, 완료 기준을 기록. Milestone 상태는 구현/정적 검토/자동 테스트/실환경 확인을 분리. 보안 문제는 비공개 신고 후 해결·공개 권고. 보안 스캔은 자동화하되 스캔 성공을 독립 보안 감사로 간주하지 않음. 위험도가 높은 변경은 독립 리뷰 및 복구 시험 후 적용. 공개 저장소 생성·이슈 등록·자동화 설정은 이 문서 작성 단계에서는 미수행.
